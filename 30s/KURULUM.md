# Çalıştırma ve yükleme

## Bilgisayarda açma
1. ZIP dosyasını çıkar.
2. `index.html`, `style.css`, `script.js` ve iki `.ttf` dosyasını aynı klasörde tut.
3. `index.html` dosyasını Safari, Chrome veya Firefox ile aç.

## GitHub Pages
1. Bu klasördeki dosyaların hepsini GitHub deposunun kök dizinine yükle.
2. Depoda **Settings → Pages** bölümüne gir.
3. **Deploy from a branch** seç; `main` ve `/ (root)` seçip kaydet.
4. Yayınlanan bağlantıyı gizli pencerede ve telefonda test et.

## Kontroller
- WASD / ok tuşları: hareket
- Ada üzerine tıkla veya sürükle: hedefe doğru ilerle
- Ekrandaki yön tuşları: dokunmatik alternatif

`script.js` içindeki `DESIGN` nesnesi, sunum sırasında değiştirilecek temel ayarları ve kuralları içerir.
